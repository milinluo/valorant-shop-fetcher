# 无畏契约每日商店自动获取器

一个给《无畏契约》国服玩家用的本地小工具：配合「无畏契约每日商店记录」网页，**自动获取当天商店刷新的 4 款皮肤**，不用再手动一个个选。

纯 Python 标准库实现，**无需安装任何第三方依赖**。

## 作用

每天商店刷新后，手动记录 4 款皮肤很麻烦。这个工具用 QQ 扫码登录一次，之后在网页里点一下「自动获取今日商店」，当天皮肤就自动记到你的记录里：

- 扫码登录一次，凭证保存在本机，之后每天直接用
- 提供本地服务（`localhost:4175`），网页按钮直接调用
- 支持网页一键唤起：网页点按钮时若工具没开，会自动启动它

## 环境要求

- 想要使用自动获取功能，电脑必须已安装 **Python 3**（未安装则双击启动脚本不会弹出二维码）
- Python 下载地址：https://www.python.org/downloads/
- 安装时务必勾选 **"Add Python to PATH"**（加入环境变量），否则启动脚本找不到 python

## 如何使用

### 1. 下载并解压

从 GitHub 下载本项目并解压（或直接拿到整个文件夹）。

### 2. 启动自动获取器

**方式一：双击启动脚本（推荐）**

双击 **`启动商店自动获取器.cmd`**。

**方式二：命令行启动**

```bash
python val_shop_fetcher.py
```

（需要电脑已安装 Python 3）

### 3. 首次扫码登录

- 第一次启动会弹出二维码图片窗口
- 用手机 **QQ 扫码**（**必须使用绑定了无畏契约游戏的 QQ 账号**）
- 扫码成功后凭证自动保存到本机 `auth.json`，窗口保持打开即可

### 4. 配合网页使用

1. 保持自动获取器窗口打开（显示"本地服务已启动"）
2. 打开「无畏契约每日商店记录」网页（`standalone\index.html`）
3. 进入「每日记录」页，点 **自动获取今日商店**
4. 当天 4 款皮肤自动入库；遇到图鉴没有的新皮肤会自动收录并提示

### 5. 让网页一键自动启动（可选）

想省去手动双击启动这步：先双击一次 **`注册网页一键启动.cmd`**（注册网页启动协议），之后在网页点「自动获取今日商店」时，如果工具没开，浏览器会弹出确认框，点"打开"就会自动启动并等待。

## 常见问题

**提示"登录凭证已失效"？**
删除本机 `auth.json`，重新运行程序扫码即可。

**端口被占用？**
说明自动获取器已经在运行，直接关掉多开的窗口，用已在运行的那个。

**腾讯调整接口后失效？**
本工具基于掌上无畏契约的非官方接口，腾讯调整后可能暂时失效，需等待工具更新。

## 注意事项

- `auth.json` 是登录凭证，相当于你的登录状态，**只保存在本机，切勿发给别人或上传**
- 二维码图片 `qr_login.png` 为运行临时产物，可随时删除
- 本工具仅用于个人记录自己的商店数据
