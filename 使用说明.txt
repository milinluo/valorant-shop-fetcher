无畏契约商店自动获取器 使用说明
====================================
上次更新：2026-10-30

【这是什么】
一个小工具：用 QQ 扫码登录一次，之后每天在网页里点「自动获取今日商店」，
就能自动把当天商店刷新的 4 个皮肤记录到你的记录里，不用再手动选。

【环境要求】
- 想要使用自动获取功能，电脑必须已安装 Python 3（未安装则双击启动脚本不会弹出二维码）
- Python 下载地址：https://www.python.org/downloads/
- 安装时务必勾选 "Add Python to PATH"（加入环境变量），否则启动脚本找不到 python

【使用方法】
1. 双击「启动商店自动获取器.cmd」（首次会弹出二维码窗口）
2. 用手机 QQ 扫码（需要用绑定了无畏契约游戏的 QQ 账号）
3. 扫码成功后凭证自动保存（auth.json），程序窗口保持打开即可
4. 打开网页（无畏契约商店记录-免安装版/无畏契约商店记录.html）
5. 在「每日记录」页点「自动获取今日商店」，当天皮肤自动入库

【打不开或界面是旧版】
- 优先双击「无畏契约商店记录.html」打开（浏览器可能缓存旧版 index.html 导致界面错乱）
- 若仍显示旧界面，在页面按 Ctrl+F5 强制刷新一次

【每天使用时】
- 先双击启动获取器，再在网页点「自动获取今日商店」
- 用完后直接关掉程序窗口即可

【注意事项】
- 登录凭证（auth.json）相当于你的登录状态，只保存在本机，请勿发给别人
- 本工具基于掌上无畏契约的非官方接口，腾讯若调整接口可能暂时失效
- 如果哪天点按钮提示「登录凭证已失效」，删除 auth.json 后重新运行本程序扫码即可
- 凭证会过期，一般登录一次能用较长时间
